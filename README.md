# Accountability Partner (working title)

A personal accountability platform: one Commitment Engine, and the freedom to choose how you are supported — on your own, with AI, with a matched partner, with a friend, or in a private group.

This repository starts with **Phase 0: Product Architecture & Validation** (see the `phase-0` branch, `docs/`). Building begins after Phase 0 is agreed. Naming and branding come later.
